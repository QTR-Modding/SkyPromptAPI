# Whats Changed?

## API 2.0.2 -> 2.0.3
Added `HandshakeKey` and `RequestHandshake` so compatible clients can share a prompt page.<br>
See Compatibility Handshakes in the [C++ tutorial](https://github.com/QTR-Modding/SkyPromptAPI/wiki/SkyPrompt-API-Tutorial-(cpp)#compatibility-handshakes) or [Papyrus tutorial](https://github.com/QTR-Modding/SkyPromptAPI/wiki/SkyPrompt-API-Tutorial-(Papyrus)#compatibility-handshakes).

## API 1.0 -> 2.0
Added a new `progress` field.
This allows authors to take control of the progress circle that appears around the buttons.<br>
Check the Advanced Features documentation for more info.
